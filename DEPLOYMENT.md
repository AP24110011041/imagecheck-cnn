GitHub Pages serves this public static website for free. The model runs in each visitor’s browser, so there is no inference server that sleeps and your laptop can be turned off. Availability remains subject to GitHub Pages service limits and outages; this is not a guaranteed uptime contract.

Push changes to `main` to publish through `.github/workflows/pages.yml`. Model and browser-runtime files are already included in `docs/`. To rebuild after retraining, follow README.md.
